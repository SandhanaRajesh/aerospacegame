# Global Student Aerospace Initiative's Aerospace Career Exploration Game (What's YOUR Flight Path)
The Global Student Aerospace Initiative's Aerospace Career Exploration Game - This is a series of space-themed minigames where users learn about the various jobs you can go into in the aerospace field in a fun way by completing minigames that correspond to the careers.

# Consists of:
-title screen that allows game to start
-level scenes in between each game to update user on lives left and the level they will be starting next
-information screens discussing what each game expects and an aerospace career spotlight explanation
-5 minigames in total
- Minigame 1: Planetary Scientist
  - jump onto platforms to deploy spacecraft onto planets
- Minigame 2: Exoplanet Researcher
  - click exoplanets to remove them from your data set
- Minigame 3: Space Journalist
  - determine reliability of a news article
- Minigame 4: Astronomer
  - click stars of Orion constellation
- Minigame 5: Flight surgeon
  - determine health level variations of astronaut
